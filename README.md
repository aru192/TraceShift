# TRACE SHIFT · DUET

[スマホで遊ぶ](https://trace-shift-puzzle.meron1902.chatgpt.site)

白い盤面で、AとBが道を作り合う全100面の協力パズルです。

## 遊び方

- AとBを交互に上下左右へドラッグし、同じ文字の輪へ運びます。1手は最大2マス。途中で指を離して交代できます。
- 普通の床は、離れた場所が壁になります。相手も自分も通れません。
- 色つきの点線は橋の材料。その色の駒が先に通って離れ、手を確定すると、相手専用の橋になります。相手が渡って離れると崩れます。
- 鍵を取って手を確定すると、同じ番号の扉が開きます。鍵1と鍵2は別々です。
- 矢印マスからは矢印の方向にだけ出られます。□に入ったら一度手を確定し、次の自分の番に動きます。
- 相手の駒・相手のゴールは通れません。到着した駒は動けず、残った駒だけが動きます。
- 指を離す前は直前のマスへ戻って取り消せます。「1手戻す」は橋、鍵、扉、手番も復元します。
- 目標手数は最短解です。超えてもクリアできます。
- クリアすると次の1面が解禁されます。解禁済みの面は再挑戦できます。

## 段階的な難易度

| 面 | 要素 |
|---|---|
| 1〜5 | 基本の道の分担 |
| 6〜15 | 相手が使う橋。6〜8面は橋を1本から練習 |
| 16〜30 | 橋と鍵・扉。最短8手以上 |
| 31〜45 | 矢印を追加。複数の橋を連携 |
| 46〜60 | 一時停止を追加。41面以降は最短10手以上 |
| 61〜75 | 2種類の鍵と扉。71面から6×6の盤面、最短12手以上 |
| 76〜100 | 複数の橋と2種類の鍵、矢印、一時停止の総合問題 |

6面以降は橋を使わずにはクリアできない配置です。鍵のある面では各種類の鍵が必須です。11面以降には解けなくなる最初の手を用意し、31面以降は正解につながる最初の手を全候補の60%以下に絞っています。

## 保存とスマホ

記録は端末・ブラウザ内の `duet_save_v4.json` に保存します。旧版のファイルは残し、配置が変わらない1〜5面の記録だけを引き継ぎます。6面以降は新しい問題として再挑戦します。解禁位置は連続してクリアした面から計算します。

スマホはHTTPSの公開URLを使ってください。同じChatGPTアカウントでログインできます。端末間の記録同期はありません。ホーム画面追加に対応。今回の変更のスマホ実機検証は未実施です。

## 開発・検証

Godot 4.7.2 / Compatibility renderer。

```sh
python3 tests/verify_campaign.py
Godot --headless --path . --log-file /tmp/duet-tests.log --script tests/regression.gd
```

`tests/bridge_solver.py` は独立した最短解探索。`tests/duet_solutions.json` に全100面の解、敗着、探索数を記録します。Godot側では全解の再生、戻して再生、橋の建設・崩落、鍵と扉、タッチ操作、未解禁の選択防止、進行保存の移行を検証します。テスト用の保存処理はメモリ内のみで、プレイヤーの記録には書き込みません。

`tests/build_bridges.py` は固定シードで6〜100面を再生成する開発用スクリプトです。`tests/progression.py` と `tests/expand_duet.py` は旧版生成用です。

```sh
Godot --headless --path . --export-release Web build/web/index.html
python3 tests/package_phone.py
```

`phone-site/` は公開用の別Gitリポジトリで、ゲーム本体からは除外しています。`phone-site/.openai/hosting.json` の既存サイトを再利用して公開してください。
